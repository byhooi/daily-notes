## 三、项目速览

"每日积累"是面向小学生的中文语言学习静态站点，原生 HTML/CSS/JavaScript + TailwindCSS，通过 **GitHub Pages** 发布，域名 `daily.yangbing.eu.org`。

五个年级入口相互独立、互不相通：`index.html`（默认五年级上）、`3A.html`、`3B.html`、`4A.html`、`4B.html`。页面**没有年级导航栏**，看得见年级链接的地方只有 `404.html`。

学习内容以 `window.dataXX` 全局数组存于 `data/*.js`，入口页预加载对应年级数据，`assets/common.js` 在 `initPage()` 中按 `gradeConfig` 识别当前年级。

详细的架构、函数职责与约定见 `CLAUDE.md`（最权威）与 `AGENTS.md`，本文档不重复。

## 五、日常工作流（踩坑点）

1. **`index.html` / `3A.html` / `3B.html` / `4A.html` / `4B.html` 由模板生成，不要直接编辑。** 改页面结构要改 `templates/page.template.html`，再跑 `npm run build:pages` 并提交生成结果。
2. **只改学习数据的文字、日期或标题，且不动样式类名时**：直接提交数据文件即可，无需构建，无需校验。
3. **改模板、Tailwind 配置，或改了扫描内容里的样式类名时**：发布前必须 `npm run build` + `npm run check:generated`，并提交有变化的 `assets/tailwind.min.css` 和入口 HTML。
4. `assets/tailwind.min.css` 与生成的入口 HTML **纳入版本控制**，供 GitHub Pages 从分支直接发布，不要再把它们加进 `.gitignore`。
5. 提交信息沿用现有风格：新增用 `add 324`（日期简写）或 `feat: 简短说明`，修复用 `fix`。
6. 内容高亮写作 `##文本##`，由 `admin.html` 生成 `<span class='highlight-red'>文本</span>`，并自动把半角标点转全角（保留数字字母半角）。
7. 仓库无部署工作流，`git push origin main` **不会**自动执行 npm 构建；实际发布来源以 GitHub 仓库 `Settings → Pages` 为准。
8. `_redirects` 是旧 Cloudflare Pages 的遗留文件，在 GitHub Pages 上**不生效**，不要据此认为旧路径仍会自动跳转。
